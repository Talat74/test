**Cloud-deployement**

A containerized Node.js application deployed on **Google Kubernetes Engine (GKE)** to practice Kubernetes deployments, troubleshooting, and application lifecycle management.

Overview

This project was built as a practical Kubernetes lab to gain hands-on experience with application deployments, rolling updates, service management, ingress configuration, and production-style troubleshooting.

It was used to simulate common operational scenarios encountered in cloud-native environments.

Technologies Used

- Node.js
- Express.js
- Docker
- Google Kubernetes Engine (GKE)
- Kubernetes
- NGINX Ingress Controller

Features

- Dockerized Node.js application
- Kubernetes Deployment
- ClusterIP Service
- Ingress configuration
- Rolling updates
- Image version updates
- Application restarts
- Health verification

Operational Tasks Performed

- Deploy application to Kubernetes
- Update Docker images
- Perform rolling deployments
- Restart deployments
- Scale application replicas
- Verify application health
- Monitor pod status
- Validate service connectivity
- Test ingress routing


Troubleshooting Experience

During this project, the following Kubernetes issues were diagnosed and resolved:

- ImagePullBackOff
- CrashLoopBackOff
- Service selector mismatches
- Ingress configuration issues
- Pod scheduling problems
- Deployment rollout failures

Skills Demonstrated

- Docker containerization
- Kubernetes administration
- Kubernetes troubleshooting
- Rolling updates
- Service management
- Ingress configuration
- Production support practices
- Incident investigation
- Root cause analysis
